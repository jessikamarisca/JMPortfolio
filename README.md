# jessikamarisca.com

Portfolio of Jessika Marisca, product designer who builds.

Built with Next.js (App Router), React and plain CSS. Deployed on Vercel.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

- `app/` pages: home and the case studies under `app/work/`
- `components/` layout, mockups (phone, browser) and video players
- `public/` images, videos and CV
